# LabDNS 1.5.1 Release Notes

Release date: 2026-10-26
Previous release: [v1.5.0](https://github.com/hilather/go-lab-dns/blob/v1.5.0/docs/releases/v1.5.0.md)
Application version: 1.5.1
Configuration versions: labdns.dev/v1alpha1
REST versions: /v1
MCP protocol versions: 2026-07-28
Container digest: unpublished

These notes are curated. They are not a commit list. They cover every functionality difference from v1.5.0. This change freezes the changelog and these notes. It does not create the `v1.5.1` tag.

## Highlights

Patch after v1.5.0: Go toolchain go1.26.10 for GO-2026-6809 ([#71](https://github.com/hilather/go-lab-dns/pull/71)) and web dev-dependency bumps ([#72](https://github.com/hilather/go-lab-dns/pull/72)). No DNS, chaos, API or configuration change.

## Added

- None.

## Changed

- Go toolchain 1.26.9 → 1.26.10 (`go.mod` `toolchain`, CI and release `GO_VERSION`, Dockerfile `golang:1.26.10-alpine`, and the current pin in `docs/11-deployment.md`, `docs/14-release-engineering.md`, `docs/22-web-ui.md`, `docs/implementation-design.md`).
- Web dev dependency `vite` 8.2.1 → 8.3.5 and `vitest` 4.1.11 → 4.1.12 (`web/package.json`, `web/package-lock.json`). Dev-only; `internal/web/dist` unchanged.

## Fixed

- None.

## Removed or deprecated

- None. The v1.5.0 deprecation of bearer tokens shorter than 32 bytes still stands; v1.6.0 refuses them.

## Security

- Go 1.26.10 picks up the crypto/x509 fix for GO-2026-6809.
- `vite` 8.3.5 fixes GHSA-9jrq-w75r-8gcw and related high-severity advisories via `launch-editor`; `vitest` 4.1.12 clears two moderate npm audit findings. Both are dev-only.
