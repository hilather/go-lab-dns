# LabDNS 1.3.2 Release Notes

Release date: 2026-09-21
Previous release: [v1.3.1](https://github.com/hilather/go-lab-dns/blob/v1.3.1/docs/releases/v1.3.1.md)
Application version: 1.3.2
Configuration versions: labdns.dev/v1alpha1
REST versions: /v1
MCP protocol versions: 2026-07-28 (default pin; optional overlay skip)
Container digest: unpublished (image build and digest pin follow this tag)

These notes are curated. They are not a commit list. They cover every functionality difference from [v1.3.1](https://github.com/hilather/go-lab-dns/blob/v1.3.1/docs/releases/v1.3.1.md).

## Highlights

Deps patch: direct dependency `github.com/modelcontextprotocol/go-sdk` 1.7.0 → 1.8.0. MCP cancel notification handling under the new SDK is covered by a poll in the cancel test. No schema, REST path, MCP tool, or CLI change.

## Added

- None. No new schema field, REST path, MCP tool, CLI flag, or capability row.

## Changed

- Direct dependency `github.com/modelcontextprotocol/go-sdk` 1.7.0 → 1.8.0. MCP cancel test polls for async `notifications/cancelled` delivery under go-sdk 1.8.

## Fixed

- None.

## Removed or deprecated

- None.

## Security

- No authentication, authorization, TLS, or CSP change. Dependency bump only.

## DNS behavior

- Unchanged.

## Chaos behavior

- Unchanged.

## REST API

- Unchanged paths and schemas. No new endpoints. The SPA remains a REST client (ADR 0008).

## MCP API and protocol compatibility

- Default remains **2026-07-28 only**. SDK is now `github.com/modelcontextprotocol/go-sdk v1.8.0` (was v1.7.0). No new tools. Manifest `sdkVersion` updated to match.
- Manifest: [api/mcp/v1.json](https://github.com/hilather/go-lab-dns/blob/v1.3.2/api/mcp/v1.json).

## Configuration and schema

- Unchanged. Schema: [api/jsonschema/labdns.dev.v1alpha1.json](https://github.com/hilather/go-lab-dns/blob/v1.3.2/api/jsonschema/labdns.dev.v1alpha1.json). Configuration versions remain `labdns.dev/v1alpha1` only.

## Deployment and operations

- Unchanged image posture, ports, and flags. Rebuild/restart onto this tag to pick up go-sdk 1.8.0.
- CLI help is unchanged: [api/cli/help.txt](https://github.com/hilather/go-lab-dns/blob/v1.3.2/api/cli/help.txt).
- Hashed operator-console assets (`web/dist`, `internal/web/dist/assets`) are not a `release-diff` surface.

## Observability

- Unchanged.

## Compatibility and migration

- Upgrade from `v1.3.1`: rebuild/restart onto this tag. Bootstrap YAML needs no migration. Canonical JSON / `sha256:` revisions of previously valid documents are unchanged.
- Observable surface change: MCP capability manifest `sdkVersion` string only. Operator-visible MCP tools and protocol pin are unchanged.
- Rollback: restore the previous image/tag pin. Runtime mutations are discarded on restart (ADR 0003).
- Config remains `labdns.dev/v1alpha1`.

## Known limitations

See the durable list: [docs/known-limitations.md](https://github.com/hilather/go-lab-dns/blob/v1.3.2/docs/known-limitations.md).

- Over-length names cannot appear on the DNS wire. UDP/TCP still cannot pack or unpack them (ADR 0007).
- Container image is still unpublished.
- Non-ASCII / IDNA names remain rejected.
