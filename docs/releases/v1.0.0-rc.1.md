## Highlights

LabDNS is a container-first laboratory DNS service: exact overrides, RFC 4592 wildcards, authoritative and overlay zones, suffix forwarding, bounded cache, and a domain-aware chaos engine. Humans and agents share one application layer through REST `/v1` and MCP Streamable HTTP `/mcp`.

First-GA decisions frozen here:

- Module **`github.com/hilather/go-lab-dns`**
- Toolchain **Go 1.26**
- Image **`ghcr.io/hilather/labdns`** (scratch, UID 65532, no shell)
- MCP **2026-07-28 only** (ADR 0006)
- Security reporting via [GitHub private advisories](https://github.com/hilather/go-lab-dns/security/advisories/new)
- Emergency control #3 is **SIGUSR1** (no Unix-socket management)

## Added

- Single static binary `labdns`: `serve`, `validate`, `canonicalize`, `verify`, `query`, `healthcheck`, `version`, `chaos emergency-disable --pid-file`.
- DNS UDP+TCP listeners (container `:5353`) and management HTTP (`:8080`) for REST `/v1` and MCP `/mcp`.
- Strict `labdns.dev/v1alpha1` YAML/JSON bootstrap, unknown-field rejection, canonical export, `sha256:` revisions.
- Local resolver: exact RRsets, closest-encloser wildcards, empty non-terminals, bounded CNAME, authoritative NXDOMAIN/NODATA+SOA, overlay fallthrough.
- Suffix forwarding with ordered / round-robin / random / health-aware pools; process-scoped positive/negative cache namespaced by revision.
- Refuse-forward default-deny: unmatched and local-only clients get local answers with RA=0 and are never forwarded.
- Chaos engine (`hash-v1`) with the first-GA effect catalog, simulation, budgets, protected objects, and three independent emergency controls.
- Shared capability registry, REST OpenAPI, MCP tools/resources/prompts, RFC 9457 problems and matching JSON-RPC `data.code`.
- Shared RBAC, abuse limits, Origin deny-all, secret redaction, in-memory audit ring.
- Metrics catalog, structured logs, optional tracing, agent-readable `GET /v1/status`.
- Hardened image, GitOps template (Compose + Kubernetes), probe suite, required CI, `scripts/release-diff`.
- PERF-001 benches, short soak/flood/admission, and client interop fixtures.

## Security

- Not an open recursive resolver. Unknown clients: local answers RA=0; REFUSED only when there is no local path; zero upstream packets.
- Management: loopback may use `dev-loopback-unauth`; remote requires bearer. `X-Forwarded-For` is not trusted. CORS writes nothing.
- Shared REST/MCP authorization. Chaos design / activate / high-impact / emergency are separate privileges. Protected objects and safety caps require administrator.
- DNS per-source rate limit (default 256/s, burst 512). Management default 32/s burst 64 plus 256 concurrent requests.
- Secrets are redacted from export, diffs, logs, and audit. Tokens live in `secretRef` / env, never in committed YAML.
- Container: non-root UID 65532, read-only root, no Linux capabilities, scratch (no shell). `make security-scan` runs govulncheck.
- Report vulnerabilities through [GitHub private vulnerability reporting](https://github.com/hilather/go-lab-dns/security/advisories/new). Do not file public issues before coordinated disclosure. Policy: [SECURITY.md](https://github.com/hilather/go-lab-dns/blob/main/SECURITY.md).

## DNS behavior

- UDP and TCP admit a single IN class QUERY, echo ID/question, set QR, and apply FORMERR/NOTIMP/BADVERS as in [docs/02-dns-semantics.md](https://github.com/hilather/go-lab-dns/blob/main/docs/02-dns-semantics.md).
- Exact A, AAAA, CNAME, TXT, MX, SRV, PTR, CAA, NS, SOA, SVCB, HTTPS plus validated generic RDATA. Wildcard NS/DNAME rejected.
- RFC 4592 closest-encloser wildcards; exact names (including empty non-terminals) win. Synthesized owner is the original QNAME.
- Authoritative miss: NXDOMAIN or NODATA + SOA; never forwarded. Overlay miss: fallthrough then suffix forward or REFUSED.
- Overlay CNAME may leave the zone and terminate in a forwarded name. Zero `CNAMEDepth` is 8, not unlimited.
- Flags: AA only on authoritative local/negative answers; RA only when this client group may forward; AD never set on local or synthesized data; CD cleared locally and passed through on forward; TC only on real truncation or explicit chaos.
- Suffix forwarding; NXDOMAIN does not fail over. Zero timeout is 500ms per attempt, stacked under the 2s query timeout. No `/etc/resolv.conf` fallback.
- Cache: revision-namespaced, TTL-clamped, LRU. Chaos cache effects operate on a copy.

## Chaos behavior

- Disabled by default. Never affects REST, MCP, liveness, readiness, or the emergency path.
- Selector specificity: record → wildcard source → owner → zone → forwarding → pool → client group → global. Composition: compose / terminal / exclusive-group.
- Algorithm **`hash-v1`** (SHA-256, ten length-prefixed fields). Goldens in [testdata/hash-v1/vectors.json](https://github.com/hilather/go-lab-dns/blob/main/testdata/hash-v1/vectors.json). `timeBucket` must be ≥ 1s. Changing inputs is a new algorithm ID.
- First-GA effects: `fixed`/`uniform` delay (four phases); RCODE/NODATA/EDE; TTL set/clamp/zero/jitter; alternate/omit/limit/shuffle/rotate; flap; UDP drop/TC; TCP close/reset/hold; cache bypass/force-miss/expire/stale; upstream delay/unavailable/force/timeout/transport-error/failover/synthetic RCODE; policy-scoped pressure. Catalog: [api/chaos/effects.json](https://github.com/hilather/go-lab-dns/blob/main/api/chaos/effects.json).
- Simulation never sleeps, writes cache, or consumes budgets.
- Emergency: (1) `--chaos-disable` / `LABDNS_CHAOS_DISABLE` startup lock; (2) authenticated `dns_chaos_emergency_disable`; (3) `SIGUSR1`. `SIGUSR2` is ignored.

## REST API

- stdlib `net/http` adapter registers every first-GA capability from the registry. Default listen `:8080`. OpenAPI 3.1: [api/openapi/v1.json](https://github.com/hilather/go-lab-dns/blob/main/api/openapi/v1.json). Capability table: [api/capabilities/v1.json](https://github.com/hilather/go-lab-dns/blob/main/api/capabilities/v1.json).
- Errors are `application/problem+json` via `capabilities.ProblemFrom`. Wrong method on a registered path is `method_not_allowed` (405).
- Health live/ready remain probe-accessible. Unauthenticated remote management is denied.
- Writes go through plan/apply (plus typed chaos activate/deactivate/expiry/emergency wrappers). No first-GA CRUD write routes.

## MCP API and protocol compatibility

- Pinned protocol **2026-07-28**. `Mcp-Protocol-Version` is required; any other value is `unsupported_protocol_version`. Manifest: [api/mcp/v1.json](https://github.com/hilather/go-lab-dns/blob/main/api/mcp/v1.json).
- Official SDK `github.com/modelcontextprotocol/go-sdk v1.7.0`. Streamable HTTP at `/mcp` is stateless.
- Tools and `labdns://` resources come from the shared registry. Domain errors use `capabilities.JSONRPCFrom` so `data.code` matches REST.
- Four read-only prompts: `plan_dns_override`, `diagnose_resolution`, `design_chaos_experiment`, `convert_runtime_drift`.
- Stdio is a developer adapter only (stderr logs, stdout protocol-clean) and is not in the production image.

## Configuration and schema

- Strict v1alpha1 decode in `internal/config`. Published schema: [api/jsonschema/labdns.dev.v1alpha1.json](https://github.com/hilather/go-lab-dns/blob/main/api/jsonschema/labdns.dev.v1alpha1.json).
- `unknownClient` is only `refuse-forward`. Empty `clientGroups` is valid. `selector.timeBucket` ≥ 1s.
- Non-ASCII names, wildcard NS/DNAME, CNAME coexistence/loops, and self-forwarding are rejected.
- Canonical JSON/YAML export materializes listen/TTL/CNAME defaults and drops comments. Revision is `sha256:` of canonical JSON.
- `Migrator` is a stub; only `labdns.dev/v1alpha1` exists. Unknown `apiVersion` is `unsupported_protocol_version`.

## Deployment and operations

- `labdns serve --config PATH` compiles bootstrap and binds DNS (default `:5353`) plus management (default `:8080`). `--management-listen=off` leaves management unbound. `--chaos-disable` arms the startup lock. `SIGTERM` is graceful.
- Image `ghcr.io/hilather/labdns`: multi-stage, scratch, UID 65532, Apache-2.0 OCI labels. Host 53→5353.
- GitOps template [examples/labdns-deploy](https://github.com/hilather/go-lab-dns/blob/main/examples/labdns-deploy/README.md): Compose + Kubernetes, digest pin, isolated management, bearer `secretRef`, policy allowlists, probe suite. Rollback restores the previous desired-state pin.
- Required CI jobs have no bypass. Tag path is the Release workflow `tag-gate` only. Operator checklist: [docs/14-release-engineering.md](https://github.com/hilather/go-lab-dns/blob/main/docs/14-release-engineering.md).
- Public-surface comparison: OpenAPI, MCP capability manifest, configuration schema, capability table, metrics catalog, CLI help, error catalog, chaos-effect catalog (`scripts/release-diff`).

## Observability

- Catalog [api/metrics/v1alpha1.json](https://github.com/hilather/go-lab-dns/blob/main/api/metrics/v1alpha1.json). Forbidden default labels: raw QNAME, client IP, actor ID, idempotency key, free-form error text.
- Telemetry backpressure drops samples (`labdns_telemetry_dropped_total`) and never blocks DNS. Series per metric capped at 256.
- `GET /v1/status` reports `ready`, `degraded`, revisions, listeners, cache, upstreams, chaos, and bounded warnings. Chaos (including emergency-disable) does not flip liveness, readiness, or degraded.
- `spec.observability.logQNAME` is the documented debug gate; default off.

## Compatibility and migration

- First install only. There is no predecessor application tag.
- Pin config `apiVersion: labdns.dev/v1alpha1`. Unknown fields fail closed.
- MCP clients must send `Mcp-Protocol-Version: 2026-07-28`.
- Rollback: restore the previous deployment-repository image digest and desired YAML; recreate the process. Runtime drift is discarded.
- Client matrix: Go wire (always), `dig` when on `PATH`, Go `net.Resolver` PreferGo. glibc / systemd-resolved / Windows are manual lab checks ([docs/16-compatibility-and-versioning.md](https://github.com/hilather/go-lab-dns/blob/main/docs/16-compatibility-and-versioning.md)).
- A later `v1.0.0` tag needs its own `docs/releases/v1.0.0.md` (this file is a starting point) and a green `tag-gate`.

## Known limitations

See the durable list: [docs/known-limitations.md](https://github.com/hilather/go-lab-dns/blob/main/docs/known-limitations.md).

- No tag, image digest, SBOM, or provenance in this candidate.
