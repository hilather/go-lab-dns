# LabDNS 1.1.0 Release Notes

Release date: 2026-08-20
Previous release: v1.0.0-rc.2
Application version: 1.1.0
Configuration versions: labdns.dev/v1alpha1
REST versions: /v1
MCP protocol versions: 2026-07-28
Container digest: unpublished (image build and digest pin follow this tag)

These notes are curated. They are not a commit list. They cover every functionality difference from [v1.0.0-rc.2](https://github.com/hilather/go-lab-dns/blob/v1.0.0-rc.2/docs/releases/v1.0.0-rc.2.md). They do **not** rewrite [v1.0.0-rc.1](https://github.com/hilather/go-lab-dns/blob/v1.0.0-rc.1/docs/releases/v1.0.0-rc.1.md) or rc.2 notes; those candidates remain UI-less.

## Highlights

Embedded operator console on the management listener (`GET /` on `:8080`): a React 19.2 SPA that is a REST client only. Every `PARITY_REQUIRED` capability is completable in the browser with the same authorization, plan/apply contract, and errors as REST/MCP (ADR 0008). Browser auth is HttpOnly cookie `labdns_session` plus CSRF; bearer tokens never land in Web Storage.

Additive v1alpha1 fields `spec.ui.enabled` (default true) and `spec.management.allowedOrigins`. Capability catalog grows 31 → 33 rows (`session`, `ui.assets`). Canonical `sha256:` revisions change for documents that omitted `spec.ui`.

Correctness fixes shipped in the same increment: REST/MCP emergency disable now cancels outstanding delays; stale plan idempotency cannot replay across a foreign mutation; overlay CNAME is no longer discarded when forwarding is refused; wildcard-after-CNAME explain source; chaos exclusive-group winners shared across Decide calls.

## Added

- Embedded operator console: login, shell, dashboard, state/export, schema, capabilities, docs, zones/records (cursor pagination), resolve/explain, forwarding/pools/upstream status, cache status/flush, chaos status/policies/simulate/activate/deactivate/expiry, audit, changes (validate → plan → apply), reset, and shell emergency disable/enable.
- `POST`/`GET`/`DELETE /v1/session`: HttpOnly cookie `labdns_session`, JSON CSRF, header `X-LabDNS-CSRF`. Bearer wins over cookie. Cookie-present `POST /v1/session` without Bearer rotates the existing Actor and does not call Identify.
- Additive `spec.ui.enabled` (omitted → true, including documents with no `spec.access`; explicit false preserved) and `spec.management.allowedOrigins` (exact `http(s)://host[:port]` Origin strings). Update-only target kind `ui` (`dns.admin`).
- Capability registry `ui` bindings on every existing row; REST-only `session` and `ui.assets`. Disposition is derived from `RESTOnly`.
- Generated OpenAPI TypeScript client (`web/src/api/openapi.d.ts`). TanStack Query: 2s status poll while visible; 5s live polls for upstreams/cache/chaos; revision invalidation.
- Vite/React toolchain (`web/`), embed stub (`internal/web`), fail-closed `make web-test` / `make web-build` / `make web-e2e`, required CI job `web` (Vitest, production build, Playwright Chromium).
- Playwright operator matrix (`web/e2e`, `testdata/web/`): login, dashboard, plan/apply a record, zone list, export, reset, resolve/explain, chaos simulate, emergency disable, viewer 403, idempotent double-click apply, a11y.
- Structured log event `ui.session`. Session routes increment `labdns_capability_calls_total{capability="session"}`. No SPA request metrics.
- GitOps/onboarding: how to open `http://127.0.0.1:8080/`, paste a bearer token, `spec.ui.enabled`, and `spec.management.allowedOrigins` in [docs/11-deployment.md](https://github.com/hilather/go-lab-dns/blob/main/docs/11-deployment.md), [docs/13-operations-and-runbooks.md](https://github.com/hilather/go-lab-dns/blob/main/docs/13-operations-and-runbooks.md), and [examples/labdns-deploy](https://github.com/hilather/go-lab-dns/blob/main/examples/labdns-deploy/README.md).

## Changed

- Canonical JSON materializes `spec.ui.enabled: true` when `spec.ui` is omitted. Content-addressed `sha256:` revisions therefore change for previously hashed documents that omitted `spec.ui`. Operators with stored `expectedRevision` from 1.0.0-rc.* must re-GET state after upgrade. Chaos `hash-v1` vectors are unaffected.
- Production image adds a digest-pinned Node 22.14.0 stage; `web/dist` is copied into `internal/web/dist` after `COPY . .`. Local `go test` still embeds the tracked stub and does not require Node.
- Required CI jobs are 13 (`web` added). `make web-test` is Vitest only; Playwright is `make web-e2e`.

## Fixed

- REST/MCP `EmergencyDisableChaos` now cancels outstanding chaos delays, matching `SIGUSR1` / `chaos.EmergencyDisable` and the documented emergency-disable contract.
- Plan idempotency cache hits re-check `expectedRevision` against the live snapshot and recompute after a foreign mutation, so a stale plan cannot be replayed. Empty `expectedRevision` is still rejected on cached Plan and Apply.
- Overlay CNAME answers are no longer discarded when forwarding is refused (unknown/local-only client, or CNAME target with no matching policy). Clients receive the local CNAME with NOERROR and RA=0.
- Wildcard synthesis after an exact CNAME now reports `source=wildcard` plus wildcard-source and closest-encloser explain fields.
- Chaos `exclusive-group` winners are shared across pre-resolution and response `Decide` calls on the same query.

## Removed or deprecated

- None. No public API, flag, schema field, or protocol version is removed. The operator console was a deferred non-goal on rc.1/rc.2 and is now a 1.1.0 feature.

## Security

- Browser session: HttpOnly `labdns_session`, `SameSite=Lax`, host-only, `Secure` iff `r.TLS != nil` (first GA HTTP → Secure false; lab-only). CSRF on cookie-authenticated non-GET. First `POST /v1/session` with no cookie omits CSRF. Cookie-present POST without Bearer does **not** call loopback Identify (no viewer→admin escalate).
- Bearer tokens are pasted into a password field and discarded after session create. Never stored in `localStorage`, `sessionStorage`, IndexedDB, URL parameters, or logs. CSRF stays in module memory.
- CSP `script-src 'self'` only (no `unsafe-inline`). No `Access-Control-Allow-*`. SPA GET/HEAD outside `/v1` and `/mcp` is pre-auth and never 401.
- Origin allowlist is YAML `spec.management.allowedOrigins` from the **active** snapshot per request. Loopback Origin remains allowed. MCP still ignores cookies.
- Session table: in-process, max 256, 12h sliding TTL. Cap reject is `rate_limited` / `session table full` (no LRU eviction of an admin session).
- Authentication, refuse-forward, RBAC, rate limits, secret redaction, and the three chaos emergency controls are otherwise unchanged from rc.2.

## DNS behavior

- Overlay CNAME that cannot fall through to forwarding is now returned locally (NOERROR, RA=0) instead of being dropped.
- Explain after exact CNAME then wildcard synthesis reports `source=wildcard` with wildcard-source and closest-encloser fields.
- No other change to exact records, flags, transports, record types, or interop fixtures.

## Chaos behavior

- Emergency disable via REST/MCP now cancels outstanding delays (parity with `SIGUSR1`).
- `exclusive-group` winners are shared across pre-resolution and response `Decide` on the same query.
- Selectors, `hash-v1`, safety caps, protected objects, and the three emergency controls are otherwise unchanged. Chaos still cannot reach the management listener, UI assets, session routes, health, or emergency HTTP.

## REST API

- Additive `/v1/session` (POST/GET/DELETE). Global OpenAPI security is bearer **or** cookie `labdns_session`. CSRF header parameter on mutating `/v1` operations (“required when authenticating with `labdns_session`; ignored for Bearer”).
- SPA `GET /` and hashed `/assets/*` are a pre-auth fallback (404 if `ui.enabled` is false); they are not authenticated registry routes.
- Existing `/v1` bodies, `Idempotency-Key`, and expected-revision headers are unchanged.
- OpenAPI: [api/openapi/v1.json](https://github.com/hilather/go-lab-dns/blob/main/api/openapi/v1.json). Capability table: [api/capabilities/v1.json](https://github.com/hilather/go-lab-dns/blob/main/api/capabilities/v1.json) (33 rows).

## MCP API and protocol compatibility

- Protocol remains **2026-07-28 only**. SDK remains `github.com/modelcontextprotocol/go-sdk v1.7.0`. No new tools. Cookies are ignored (off-loopback cookie-only MCP is 401). Origin allowlist is the same YAML `spec.management.allowedOrigins` as REST, read per request from the active snapshot.
- Manifest: [api/mcp/v1.json](https://github.com/hilather/go-lab-dns/blob/main/api/mcp/v1.json) (identical to rc.2).

## Configuration and schema

- Additive `spec.ui` (`enabled` bool) and `spec.management.allowedOrigins` (array of Origin strings). `target.kind` `ui` is an update-only singleton.
- Omitted `spec.ui` / omitted `enabled` materializes `true` even when `spec.access` is absent. Explicit `false` is preserved. Invalid Origins fail `invalid_value`; unknown `spec.ui` fields fail `unknown_field`.
- Schema: [api/jsonschema/labdns.dev.v1alpha1.json](https://github.com/hilather/go-lab-dns/blob/main/api/jsonschema/labdns.dev.v1alpha1.json).

## Deployment and operations

- Image still `golang:1.26.6-alpine` → scratch, UID 65532, plus a digest-pinned Node 22.14.0 stage that must emit `index.html` and a non-empty `assets/` directory.
- Open the console at `http://127.0.0.1:8080/` (Compose maps `127.0.0.1:8080:8080`). Loopback: Continue as local administrator. GitOps bearer: paste the token. `spec.ui.enabled: false` 404s SPA only. `--management-listen=off` unbinds REST, MCP, and UI together.
- CLI help is unchanged: [api/cli/help.txt](https://github.com/hilather/go-lab-dns/blob/main/api/cli/help.txt).
- Required CI jobs now include `web`. Operator checklist: [docs/14-release-engineering.md](https://github.com/hilather/go-lab-dns/blob/main/docs/14-release-engineering.md).

## Observability

- New structured log event `ui.session` (`actor_id` is token or identity id, never cookie/CSRF/bearer value). Catalog: [api/metrics/v1alpha1.json](https://github.com/hilather/go-lab-dns/blob/main/api/metrics/v1alpha1.json).
- Session routes use `labdns_capability_calls_total{capability="session",transport="rest"}`.
- No SPA path metrics and no `labdns_capability_calls_total{capability="ui.assets"}` in 1.1.0 (pre-auth branch never calls `observe()`).
- Dashboard SoT remains `GET /v1/status` (2s poll while visible).

## Compatibility and migration

- Upgrade from `v1.0.0-rc.2`: rebuild/restart onto this tag. Re-GET `runtimeRevision` before plan/apply (`spec.ui` materialization changes Canonical hashes). Bootstrap YAML needs no migration; omitted `ui` enables the console.
- Operators who must not expose HTML set `spec.ui.enabled: false` (no restart required for SPA 404; listen addresses still do not rebind).
- Rollback: restore the previous image digest / desired-state pin and recreate the process (ADR 0003). Runtime mutations and in-process sessions are discarded.
- Config remains `labdns.dev/v1alpha1`. MCP clients must still send `Mcp-Protocol-Version: 2026-07-28`.
- Hashed `web/dist` is not a `release-diff` surface.

## Known limitations

See the durable list: [docs/known-limitations.md](https://github.com/hilather/go-lab-dns/blob/main/docs/known-limitations.md).

- Container image is still unpublished; GitOps digest placeholder remains all-zero until `ghcr.io/hilather/labdns` is built from this tag and pinned.
- Durable audit is best-effort, not fail-closed.
- Absolute QPS/p99 not CI-gated; long soak is opt-in. The 24h pre-GA soak was not executed (2s CI soak only).
- Delay distributions: `fixed` and `uniform` only. DoT/DoH/DoQ, Unix-socket management, extra MCP protocol versions, and ADR 0007 malformed-wire remain out of first GA.
- Config is v1alpha1 only. Snapshot ring is one previous generation. MCP stdio is not in the production image.
- Console follow-ons not in 1.1.0: SSE, OAuth/OIDC, management TLS, multi-replica sessions, token-file reread. Cookie `Secure` is false on HTTP. Local `go test` embeds the stub, not the production SPA.
