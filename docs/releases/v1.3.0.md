# LabDNS 1.3.0 Release Notes

Release date: 2026-08-29
Previous release: [v1.2.0](https://github.com/hilather/go-lab-dns/blob/v1.2.0/docs/releases/v1.2.0.md)
Application version: 1.3.0
Configuration versions: labdns.dev/v1alpha1
REST versions: /v1
MCP protocol versions: 2026-07-28 (default pin; optional overlay skip)
Container digest: unpublished (image build and digest pin follow this tag)

These notes are curated. They are not a commit list. They cover every functionality difference from [v1.2.0](https://github.com/hilather/go-lab-dns/blob/v1.2.0/docs/releases/v1.2.0.md).

## Highlights

The embedded operator console is LabDNS dark. Primary nav is grouped Inspect / Mutate / Ref and includes Reset. `/zones` is an inventory rail plus selected-zone records; Create/Edit/Delete and Create record hop to `/changes` with operations prefilled (the `mutations in UI-003` stub is gone). `/login` and the remaining operator pages use the same charcoal/amber chrome as `/zones`. Routes, CSRF, and REST/MCP behavior are unchanged. This is not a DNS protocol change.

Also includes the already-landed operator README MCP (`/mcp`) documentation fix so the default **2026-07-28** pin and `allowLegacyClients` overlay match ADR 0006.

## Added

- None. No new schema field, REST path, MCP tool, CLI flag, or capability row. Reset already existed; the nav now lists it (Changed).

## Changed

- Operator console shell is LabDNS dark. Primary nav is grouped Inspect / Mutate / Ref and includes Reset. The header shows one emergency verb (Disable when chaos is live, Enable when inhibited).
- `/login` and the remaining operator pages (`/`, `/state`, `/changes`, `/zones/:zoneId/records/:recordId`, `/resolve`, `/forwarding`, `/cache`, `/chaos`, `/chaos/:policyId`, `/audit`, `/audit/:eventId`, `/schema`, `/docs`, `/docs/:id`, `/capabilities`, `/reset`) use the same charcoal/amber chrome as `/zones` (`#0d0d0c` / `#161614` / `#f2efe6`, accent `#e09a3e`). Mutations still enqueue via `/changes`.
- `/zones` is an inventory rail plus selected-zone records (Owner, Type, TTL, Values, Chaos, ID). Create/Edit/Delete and Create record hop to `/changes` with operations prefilled. The `mutations in UI-003` stub is removed.
- `make web-test` / `npm test` now run `tsc --noEmit` before Vitest (same typecheck the image `npm run build` already ran).

## Fixed

- Unknown `/zones/:zoneId` shows one `not_found` alert (not two from zoneQuery + recordsQuery). Fixes #34.
- Operator image `npm run build` (`tsc --noEmit`) no longer typechecks Vitest files (`web/tsconfig.json` excludes `src/**/*.test.ts` and `src/**/*.test.tsx`), so `chrome.test.ts` `node:fs` imports do not fail the container web build.
- Operator README MCP (`/mcp`) section now matches ADR 0006 and [docs/07-mcp-api.md](https://github.com/hilather/go-lab-dns/blob/v1.3.0/docs/07-mcp-api.md): default pin remains **2026-07-28** (`Mcp-Protocol-Version` required); `spec.management.mcp.allowLegacyClients: true` skips the HTTP pin so MCPJungle can initialize without that header. The knob itself shipped in [v1.1.1](https://github.com/hilather/go-lab-dns/blob/v1.1.1/docs/releases/v1.1.1.md).

## Observability

- Unchanged.

## Compatibility and migration

- Upgrade from `v1.2.0`: rebuild/restart onto this tag. Bootstrap YAML needs no migration. Canonical JSON / `sha256:` revisions of previously valid documents are unchanged.
- Rollback: restore the previous image/tag pin. The light leftover-page chrome and ungrouped nav return; Reset leaves the primary nav; the header shows both emergency verbs again; zone Create/Edit/Delete become disabled `mutations in UI-003` stubs. Runtime mutations are discarded on restart (ADR 0003).
- Config remains `labdns.dev/v1alpha1`.

## Known limitations

See the durable list: [docs/known-limitations.md](https://github.com/hilather/go-lab-dns/blob/v1.3.0/docs/known-limitations.md).

- Over-length names cannot appear on the DNS wire. UDP/TCP still cannot pack or unpack them (ADR 0007).
- Container image is still unpublished.
- Non-ASCII / IDNA names remain rejected.
