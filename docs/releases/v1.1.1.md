# LabDNS 1.1.1 Release Notes

Release date: 2026-08-23
Previous release: [v1.1.0](https://github.com/hilather/go-lab-dns/blob/v1.1.0/docs/releases/v1.1.0.md)
Application version: 1.1.1
Configuration versions: labdns.dev/v1alpha1
REST versions: /v1
MCP protocol versions: 2026-07-28 (default pin; optional overlay skip)
Container digest: unpublished (image build and digest pin follow this tag)

These notes are curated. They are not a commit list. They cover every functionality difference from [v1.1.0](https://github.com/hilather/go-lab-dns/blob/v1.1.0/docs/releases/v1.1.0.md).

## Highlights

Additive `spec.management.mcp.allowLegacyClients` (default **false**) so an orchestrator can register MCPJungle without a local protocol-pin patch. Default Streamable HTTP still pins **2026-07-28 only** (ADR 0006). The knob skips the HTTP-level pin; it does not add a claimed MCP protocol version.

Also includes the already-landed `github.com/miekg/dns` 1.1.72 → 1.1.73 bump from `main` after v1.1.0.

## Added

- `spec.management.mcp.allowLegacyClients` (bool, omitted → false). When true, skip `Mcp-Protocol-Version` enforcement and the discover `_meta` pin so older SDK clients can initialize. Read per request from the active snapshot (same as `allowedOrigins`).

## Changed

- Direct dependency `github.com/miekg/dns` 1.1.72 → 1.1.73.
- ADR 0006 records the overlay knob as an amendment. Default remains 2026-07-28 only.

## Fixed

- None.

## Removed or deprecated

- None.

## Security

- No authentication, authorization, or TLS changes. The overlay knob is lab-only compatibility for older MCP SDKs; leave it false on internet-facing deployments.

## DNS behavior

- Unchanged aside from the miekg/dns patch-level bump.

## Chaos behavior

- Unchanged.

## REST API

- Unchanged. No new paths.

## MCP API and protocol compatibility

- Default remains **2026-07-28 only**. SDK remains `github.com/modelcontextprotocol/go-sdk v1.7.0`. No new tools.
- `allowLegacyClients: true` lets initialize proceed without `Mcp-Protocol-Version: 2026-07-28`. `subscriptions`/discover pin middleware is skipped when the snapshot says true.
- Manifest: [api/mcp/v1.json](https://github.com/hilather/go-lab-dns/blob/main/api/mcp/v1.json) (unchanged).

## Configuration and schema

- Additive nested `spec.management.mcp` with `allowLegacyClients`. Unknown `mcp` keys fail `unknown_field`. Omitted `mcp` does not change Canonical JSON (omitempty).
- Schema: [api/jsonschema/labdns.dev.v1alpha1.json](https://github.com/hilather/go-lab-dns/blob/main/api/jsonschema/labdns.dev.v1alpha1.json).

## Deployment and operations

- Unchanged image posture, ports, and flags. Set the YAML field and recreate/reload the process (or plan/apply; the adapter reads the live snapshot).
- CLI help is unchanged.

## Observability

- Unchanged.

## Compatibility and migration

- Upgrade from `v1.1.0`: rebuild/restart onto this tag. Bootstrap YAML needs no migration. To let MCPJungle register, set `spec.management.mcp.allowLegacyClients: true`.
- Rollback: restore the previous pin. Documents that never set `mcp` hash-match v1.1.0 Canonical JSON.
- Config remains `labdns.dev/v1alpha1`.

## Known limitations

See the durable list: [docs/known-limitations.md](https://github.com/hilather/go-lab-dns/blob/main/docs/known-limitations.md).

- Extra MCP protocol versions are still not claimed. The overlay knob is a pin skip, not multi-version support.
- Container image is still unpublished.
